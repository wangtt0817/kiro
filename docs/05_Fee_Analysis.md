# MemeMax 手续费分析与盈亏平衡点计算

## 费率结构

| 类型 | 费率 |
|------|------|
| Taker（吃单） | 0.15% |
| Maker（挂单） | 0.005% |

**比例：Taker 是 Maker 的 30 倍！** 这是策略设计的核心基石。

---

## 配对交易单轮成本分析

一次完整配对交易 = 同时操作 BTC 和 ETH 两腿

```
开仓：2 笔订单（BTC 一腿 + ETH 一腿）
平仓：2 笔订单（BTC 一腿 + ETH 一腿）
单轮总计：4 笔订单
```

### 场景对比

#### 场景 A：全部用 Maker 单（挂单）— 最优

```
成本 = 4 笔 × 0.005% = 0.02%
→ 价差盈利只需 > 0.02% 即可获利
→ 极其容易覆盖 ✅
```

#### 场景 B：开仓 Maker + 平仓 Taker（常见：开仓挂单，平仓急着走用吃单）

```
成本 = 2 笔 Maker（开仓）+ 2 笔 Taker（平仓）
     = 2 × 0.005% + 2 × 0.15%
     = 0.01% + 0.30% = 0.31%
→ 价差盈利需要 > 0.31% 才能获利
→ 较难覆盖 ⚠️
```

#### 场景 C：全部用 Taker 单（吃单）— 最差

```
成本 = 4 笔 × 0.15% = 0.60%
→ 价差盈利需要 > 0.60%
→ 高频几乎不可能覆盖 ❌
```

#### 场景 D：一腿被迫 Taker（平仓单腿失败的情况）

```
成本 = 2 笔 Maker（开仓）+ 1 笔 Maker（平仓）+ 1 笔 Taker（平仓）
     = 3 × 0.005% + 1 × 0.15%
     = 0.015% + 0.15% = 0.165%
→ 这一轮亏损手续费约 0.145%
→ 但消除了单腿敞口风险，值得付出
```

---

## 策略结论

| 方案 | 单轮成本 | 可行性 | 成交频率 |
|------|---------|--------|---------|
| 全 Maker | 0.02% | ⭐⭐⭐⭐⭐ 极佳 | 取决于挂单成交速度 |
| 开 Maker + 平 Maker | 0.02% | ⭐⭐⭐⭐⭐ 极佳 | 最优但需要耐心 |
| 开 Maker + 平 Taker | 0.31% | ⭐⭐ 困难 | 快但成本高 |
| 全 Taker | 0.60% | ❌ 不可行 | 最快但必亏 |

**关键策略决定：必须用 Maker 挂单来开仓和平仓！0.005% 的 Maker 费率是核心优势。**

## 目标利润设定

```
每轮利润目标：0.05%（毛利）
扣除手续费：-0.02%
净利：0.03%

通过高频次累积：
  日 20 轮 → 日净利 0.6%  → 月 18%
  日 30 轮 → 日净利 0.9%  → 月 27%
  日 50 轮 → 日净利 1.5%  → 月 45%
```

## 成交量计算

假设每轮 $2,000 名义 × 2 腿 × 开平 = $8,000/轮：

| 频率 | 日成交量 | 月成交量 |
|------|---------|---------|
| 50 轮/天 | $400,000 | $12M |
| 30 轮/天 | $240,000 | $7.2M |
| 20 轮/天 | $160,000 | $4.8M |

## 手续费敏感性分析

如果 Maker 费率改变：

| Maker 费率 | 单轮成本（4笔） | 目标毛利 | 可行性 |
|-----------|---------------|---------|--------|
| 0.005% | 0.02% | 0.05% | ✅ 当前 |
| 0.01% | 0.04% | 0.08% | ✅ 仍可行 |
| 0.02% | 0.08% | 0.15% | ⚠️ 勉强 |
| 0.05% | 0.20% | 0.30% | ❌ 困难 |

---

## 关键原则

1. **永远优先使用 Maker 订单**
2. **仅在平仓单腿失败超过 5 次后才使用 Taker**（防止单腿裸露敞口）
3. **目标毛利必须 ≥ 手续费 × 2**（留足空间应对滑点和异常情况）
4. **记录每笔交易的实际成本**，持续监控真实 Maker 成交率
