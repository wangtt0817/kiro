# 高频执行引擎设计

## 核心思路

**不是等大偏离再交易，而是捕捉 ETH/BTC ratio 的微小波动，快进快出，刷量为主。**

---

## 策略架构

```
┌─────────────────────────────────────────────────────────────┐
│                    高频 Ratio Scalping                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  输入：ETH/BTC ratio 实时价格                                │
│                                                             │
│  信号：ratio 偏离短期均值 > 最小阈值（覆盖手续费+微利）       │
│                                                             │
│  开仓：挂 Maker 限价单（BTC 一腿 + ETH 一腿）                │
│                                                             │
│  平仓：ratio 回归时挂 Maker 限价单平仓                       │
│                                                             │
│  目标：每轮利润 0.03%-0.05%（净利 0.01%-0.03%）              │
│  频率：尽可能高（每分钟级别扫描，有信号就开）                  │
│  仓位：小仓多次                                              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 信号逻辑（极短周期均值回归）

```
时间框架：1 分钟 K 线（或 tick 级别）
均值窗口：10-30 根 K 线（10-30 分钟）

ratio = ETH_mark_price / BTC_mark_price

# 超短期均值
ratio_ma = EMA(ratio, period=20)  # 20 分钟 EMA

# 偏离度（不用 Z-Score，直接用百分比偏离）
deviation = (ratio - ratio_ma) / ratio_ma * 100%

# 开仓条件（极小阈值）
OPEN_THRESHOLD = 0.05%   # ratio 偏离均值 0.05% 就开仓
CLOSE_THRESHOLD = 0.00%  # 回到均值就平仓（赚偏离的 0.05%）
MAX_HOLD_TIME = 30min    # 最长持仓时间，超时强平

信号：
  deviation < -0.05% → 做多 ETH PERP + 做空 BTC PERP（ratio 偏低，会回升）
  deviation > +0.05% → 做空 ETH PERP + 做多 BTC PERP（ratio 偏高，会回落）
  |deviation| < 0.01% → 平仓（回归完成）
```

## 开平仓执行逻辑（全 Maker）

### 开仓流程

```
┌──────────────────────────────────────────────────┐
│ 1. 信号触发：deviation > OPEN_THRESHOLD           │
│                                                  │
│ 2. 计算挂单价格：                                 │
│    BTC_limit = BTC_best_bid（挂买单，排队）       │
│    ETH_limit = ETH_best_ask（挂卖单，排队）       │
│    → 排在盘口最优位置，享受 Maker 费              │
│                                                  │
│ 3. 先挂 ETH（流动性较差），后挂 BTC               │
│                                                  │
│ 4. 等待成交：                                     │
│    两腿都成交 → 进入持仓状态                      │
│    超过 5 秒只成交一腿 → 撤销未成交腿             │
│    已成交腿用 Maker 反向平掉（避免单腿敞口）       │
│    超过 10 秒都没成交 → 撤单，等下一个信号         │
└──────────────────────────────────────────────────┘
```

### 平仓流程（详见文档 07）

```
┌──────────────────────────────────────────────────┐
│ 两腿同时挂 Maker 平仓单（关键：同时，不顺序）      │
│                                                  │
│ - 两腿都成交 → 完美 ✅                            │
│ - 一腿成交另一腿失败 → CLOSING_REMAINING 紧急模式 │
│   * 每 1 秒刷新订单价格                           │
│   * 最多重试 5 次                                 │
│   * 失败后强制 Taker（保证平仓，付 0.15%）        │
│ - 两腿都没成交 → 每 3 秒刷新价格                  │
└──────────────────────────────────────────────────┘
```

## 核心参数设计

```
手续费成本（全 Maker）：0.02% / 轮
目标毛利：0.05% / 轮（保守）
净利润：0.03% / 轮

假设每天完成 50 轮 交易：
  日净利 = 50 × 0.03% = 1.5%
  月净利 = 1.5% × 30 = 45%（理想状态）

假设每天完成 20 轮（保守）：
  日净利 = 20 × 0.03% = 0.6%
  月净利 = 0.6% × 30 = 18%
```

## 仓位管理

```
总资金：$10,000（示例）
单轮仓位：$1,000 名义 / 每腿（2x 杠杆 → 保证金 $500/腿）
最大同时持仓：3 轮（$3,000 名义 × 2 腿 = $6,000）
保证金占用上限：60%（$6,000 / $10,000）

分层开仓：
  第 1 层：deviation > 0.05% → 开 1 份
  第 2 层：deviation > 0.08% → 再开 1 份（加仓）
  第 3 层：deviation > 0.12% → 再开 1 份（极端偏离）
  → 均价更好，回归时利润更大
```

## 风控规则

```
单轮止损：
  deviation 反向扩大到 0.15% 且 持续超过 5 分钟 → 止损
  止损方式：Maker 挂单（优先）→ 3 秒未成交改 Taker

日度风控：
  日亏损 > 0.5% → 暂停 1 小时
  日亏损 > 1.0% → 当日停止交易
  
连续亏损：
  连续 5 轮亏损 → 暂停 30 分钟
  → 可能市场进入趋势模式，均值回归失效

保证金监控：
  保证金使用率 > 70% → 不再开新仓
  保证金使用率 > 85% → 开始平仓最老的持仓
```

## 策略状态机

```
           ┌─────────┐
           │  IDLE   │ ←─── 撤单/放弃
           └────┬────┘
                │ 信号触发
                ▼
        ┌───────────────┐
        │ OPENING_LEG1  │  挂 ETH 限价单
        └───────┬───────┘
                │ ETH 成交
                ▼
        ┌───────────────┐
        │ OPENING_LEG2  │  挂 BTC 限价单
        └───────┬───────┘
           │         │
     BTC成交│         │BTC 超时
           ▼         ▼
    ┌──────────┐  ┌──────────────┐
    │ HOLDING  │  │   ABORTING   │ 撤 BTC + 平 ETH
    └────┬─────┘  └──────────────┘
         │
         │ 达到目标 / 信号平仓 / 超时 / 止损
         ▼
    ┌──────────────────┐
    │   CLOSING_BOTH   │  两腿同时挂 Maker 平仓
    └────────┬─────────┘
         │         │         │
    都成交│    一腿成交    都未成交
         │         │         │
         ▼         ▼         ▼
      ┌────┐ ┌──────────┐  (refresh)
      │DONE│ │ REMAINING│ ← 紧急模式（详见文档 07）
      └────┘ └──────────┘
```

## 调参建议（追求更高成交量）

如果交易频率不够：
- 降低 `OPEN_THRESHOLD`：0.05% → 0.03%（更容易触发）
- 缩短 `EMA_PERIOD`：20 → 10（更敏感）
- 降低 `TARGET_PROFIT`：0.05% → 0.03%（更快平仓）
- 缩短 `SCAN_INTERVAL`：2 秒 → 1 秒

如果亏损过多：
- 提高 `OPEN_THRESHOLD`：0.05% → 0.08%
- 延长 `EMA_PERIOD`：20 → 40
- 缩短 `MAX_HOLD_SECONDS`：1800 → 600
- 加入趋势过滤器（趋势明确时不开仓）
