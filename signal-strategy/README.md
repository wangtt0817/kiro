# signal-strategy — 多方向信号交易框架

把 `analysis_outputs/` 里的**真实交叉分析结论**（Grafana 盈亏信号 × Gate 30m K线，
2026-04-27 ~ 2026-05-27）转化为可运行、可回测、可插入真实数据的策略代码。

> 核心立场：真实数据证明**朴素"跟随盈利信号"几乎无 edge**（信号与未来价格相关系数≈0，
> 跟随后 3/6 根 K线收益中位数 −0.08% / −0.22%）。真正的 edge 藏在**条件结构**里——
> 价格位置、时段、波动状态、标的。本框架把这些条件做成可组合的过滤层。

---

## 1. 六个方向 (Directions)

| 方向 | 名称 | 类型 | 文件 | 数据依据 |
|------|------|------|------|----------|
| A | 反追涨均值回归 | 主策略 | `signals.py:signal_reversion` | STEP 7 滞后分桶 |
| B | 恐慌反转抄底 | 主策略 | `signals.py:signal_capitulation` | STEP 6 超大盈利层 |
| C | 趋势/震荡判别 | 开关层 | `regime.py` | state_summary stress/stable |
| D | 时段执行闸门 | 全局乘子 | `session.py` | STEP 9 时段热力 |
| E | 标的白/黑名单 | 过滤层 | `universe.py` | STEP 8 代币盈亏 |
| F | 足球策略真实退出修复 | 验证 | `football_fix.py` | 前两轮代码审查 |

### 方向 A — 反追涨均值回归（核心）
STEP 7 按"信号出现时价格过去3h已涨幅"分桶后的未来收益：

| 已涨幅 | 后续3根上涨率 | 后续6根中位 | 动作 |
|--------|---------------|-------------|------|
| <1% | 50.3% | −0.16% | 不交易（信号滞后无方向）|
| 3–5% | 51.0% | **+0.25%** | 跟随做多（甜区）|
| 5–10% | 44.8% | −0.10%（3根 −0.65%）| **fade 做空** |
| >10% | 45.9% | **−1.88%** | **强 fade 做空** |

### 方向 B — 恐慌反转抄底
STEP 6 超大盈利（>1000U）：过去3h跌幅中位 **−11.2%**，未来1根 **+3.04%**，上涨率 54.1%。
触发 = 急跌(≤−8%) + 大额信号(≥500U) + 止跌确认(ret_5m≥0)，做多反弹，持 2 根，止损 3%。

### 方向 C — 趋势/震荡判别
高振幅(amp_15m≥6) / 放量(vol_ratio≥3) / 强动量(|ret_5m|≥3) ⇒ `trend`，压低逆势仓位；
低振幅 + 量比正常 ⇒ `range`，均值回归全力。

### 方向 D — 时段执行闸门
STEP 9：10/14/16 UTC 胜率 59–61%；07/23 UTC 净 −266K/−542K。映射为 0.0–1.0 仓位乘子，
0.0 = 禁止开新仓（07/19/21/23 UTC）。**确定性最高、成本最低，建议第一个上线。**

### 方向 E — 标的白/黑名单
STEP 8：白名单 lab/skyai/beat/bsb/wld…（结构性盈利）；黑名单 btc(单独 −390K)/gua/zkj/siren…
生产环境改用 `universe.rolling_score()` 动态评分，避免写死过拟合。

### 方向 F — 足球策略真实退出修复
独立、诚实的足球做市/趋势回测：退出价用**真实未来价格**而非 `_simulate_price_change`，
并对做市建模**逆向选择**。用来量化原框架"近乎100%胜率"被夸大了多少。

## 2. 快速开始

```bash
# 进入目录运行（标准库依赖，无需安装任何第三方包）
cd signal-strategy

# 合成数据自检（标定到真实统计）
python3 signal_strategy.py --events 20000 --seed 7

# 方向 F：足球真实退出 vs 模拟退出对照
python3 signal_strategy.py --football

# 接入真实合并数据
python3 signal_strategy.py --csv your_merged.csv
```

### 合成数据自检的代表性结果

| 策略 | 胜率 | ROI | 盈亏比 | 最大回撤 |
|------|------|-----|--------|----------|
| 多方向 (A+B+全过滤) | ~55.5% | +17% | 1.45 | 1.1% |
| 朴素跟随基线（追涨无过滤）| ~45% | −38% | 0.75 | 38% |

样本内/样本外胜率接近（55.4% / 55.9%）→ 规则稳健、过拟合风险低。

> ⚠️ 这是**合成数据自检**：合成器把真实条件结构（滞后桶/时段/stress/标的/capitulation）
> 显式写入未来收益，因此"多方向能跑赢、朴素会亏"验证的是**逻辑正确性**，
> 不是真实收益。真实 edge 必须用 `--csv` 接入真实合并数据复现。

## 3. 数据 schema（接入真实数据）

把你的 Grafana 信号与 Gate K线按时间对齐后，导出为 CSV，列如下（缺列置 0/None）：

| 列 | 含义 |
|----|------|
| `ts` | UTC 时间戳 (ISO8601，可含 Z) |
| `contract` | 合约名，如 `lab_usdt` |
| `gf_score_30m` | Grafana 30m 累计盈亏 (U) |
| `gf_delta_5m` / `gf_delta_15m` | 分数 5/15 分钟变化 |
| `price` | Gate 当根收盘价 |
| `past_ret_3h` | 过去 3 小时涨跌幅 (%) — **方向 A 分桶用** |
| `ret_5m` / `ret_15m` / `ret_30m` | 近 5/15/30 分钟收益 (%) |
| `amp_15m` | 15 分钟振幅 (%) |
| `vol_ratio_5v30` | 近5min/近30min 成交量比 |
| `fwd_ret_1` / `fwd_ret_3` / `fwd_ret_6` | 未来 1/3/6 根收益 (%) — **仅回测需要** |

口径：1 根 K线 = 30 分钟；持仓 6 根 = 3 小时。实盘流式接入时 `fwd_ret_*` 留空。

`load_events_csv(path)` 会读成 `EventRow` 列表，直接喂给 `run_backtest`。

## 4. 文件结构（单文件版）

全部逻辑合并在 `signal_strategy.py` 一个文件内，按依赖顺序分 11 个章节
（文件内用 `[n] 章节名` 注释分隔，便于定位）：

```
signal-strategy/
├── signal_strategy.py   全部逻辑（单文件，标准库依赖，零第三方包）
├── README.md            本文档
└── .gitignore

signal_strategy.py 内部章节:
  [1]  CONFIG     所有真实数据标定常量（改这里即可调参）
  [2]  DATAFEED   EventRow schema + 真实CSV加载 + 标定合成生成器
  [3]  FEATURES   滞后分桶 / stress 标志 / capitulation 判定
  [4]  SESSION    方向 D：时段乘子
  [5]  UNIVERSE   方向 E：白/黑名单 + 动态评分
  [6]  REGIME     方向 C：趋势/震荡判别
  [7]  SIGNALS    方向 A/B：信号生成（叠加全部过滤）
  [8]  PORTFOLIO  仓位计算 + 账户级风控（日亏限额/并发）
  [9]  BACKTEST   事件驱动回测引擎 + 指标 + 多维归因
  [10] FOOTBALL   方向 F：足球真实退出修复
  [11] RUN        CLI 入口（含朴素基线 + 样本内外切分）
```

信号流水线：
`EventRow → derive(features) → stress否决 → 方向逻辑(A/B) → session×universe×regime 置信 → position_notional → 真实fwd_ret结算`

## 5. 推荐上线顺序与组合权重

| 优先级 | 内容 | 理由 |
|--------|------|------|
| 1 | 方向 D 时段闸门 | 确定性最高、零额外成本 |
| 2 | 方向 C 趋势过滤 + E 标的过滤 | 剔除最大亏损源（如 btc） |
| 3 | 方向 A 反追涨（40%）| edge 最干净 |
| 4 | 方向 B 恐慌反转（25%）| 与 A 低相关 |
| 并行 | 方向 F | 验证旧框架，不参与实盘 |

A/B 都是逆势但触发条件相反（A=fade 涨幅，B=抄跌幅），天然低相关；C/D/E 是过滤层不占独立仓位。

## 7. 三个必须正视的风险

1. **样本期仅约 1 个月**：时段规律、标的名单都可能漂移 → 全部用滚动窗口，季度复核。
2. **生存者偏差**：Grafana 信号来自"已在交易的人"，本身有选择偏差。
3. **过拟合**：方向 A 的 7%/阈值、方向 E 的名单易过拟合 → 阈值做区间扫描看稳健性，名单用动态评分。
