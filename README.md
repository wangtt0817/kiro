# BTC/ETH 同交易所对冲策略（MemeMax Perp DEX）

> **MemeMax 是纯永续合约 DEX（Perp DEX）**：只有合约，无现货、无期权、无交割合约。
> 所有策略设计完全基于这一约束。

---

## 一、交易所约束（核心前提）

| 项目 | 值 |
|------|------|
| 交易所 | **MemeMax**（Perp DEX，2026 年 4 月上线） |
| 可交易品种 | 仅 **BTC PERP, ETH PERP**（永续合约） |
| **没有** | 现货、期权、交割合约、跨交易所转账 |
| Maker 费率 | **0.005%** |
| Taker 费率 | **0.15%**（是 Maker 的 30 倍） |
| 资金费率结算 | 8 小时 |
| 同品种多空 | 不允许（必须用跨品种 BTC↔ETH 对冲） |
| API | 支持自动化 |

---

## 二、策略选择

由于交易所约束，传统对冲方法大多不可用：

| 策略 | 需要 | MemeMax 是否可行 |
|------|------|------------------|
| 现货 + 合约 Delta 中性 | 现货 | ❌ |
| 资金费率套利（基差） | 现货 | ❌ |
| 期现基差套利 | 现货 + 交割合约 | ❌ |
| 波动率套利 | 期权 | ❌ |
| **BTC/ETH 双 PERP 配对交易** | 仅永续 | **✅ 唯一可行** |

**核心策略：BTC/ETH Ratio 均值回归配对交易 + 全 Maker 限价单。**

---

## 三、策略概览

- 监控 ETH/BTC 价格比率对短期 EMA 的偏离
- 偏离 > 0.05% 开仓（多 BTC PERP / 空 ETH PERP，或反之）
- 回归均值时平仓
- **所有订单使用 Maker 限价单**（费率 0.005% vs Taker 0.15%）
- 每轮成本仅 0.02%，目标毛利 0.05%，净利 0.03%
- 目标频率：每天 20-50 轮，产生 $160k - $400k 的成交量

详细设计：[`docs/01_MAIN_Strategy.md`](docs/01_MAIN_Strategy.md)

## 八、核心风险（必读）

### 1. 方向性风险（最大风险）

纯 PERP 环境下，BTC 多 + ETH 空 ≠ 完全对冲。
你暴露在 **ETH/BTC ratio 变化**的风险中——这是收益的来源，也是亏损的来源。

### 2. 双边资金费率拖累

两腿都是合约，两腿都要付/收资金费率。
**最糟情况**：两边都对你不利时，每 8 小时净支出 0.15%（年化 200%+ 拖累）。
→ 开仓前必须检查两边资金费率方向。

### 3. 单腿强平 → 裸露敞口

如果一腿被强平，另一腿就变成纯方向性头寸。
→ 杠杆 ≤ 3x，保证金使用率 ≤ 60%，留足缓冲。

### 4. 平仓时单腿失败

最危险的场景：一边平了，另一边没平。
→ 已设计三级防护（同时下单 → 紧急 Maker → 强制 Taker），详见 [`docs/04_SingleLeg_Failure.md`](docs/04_SingleLeg_Failure.md)。

### 5. MemeMax 自身风险

新 DEX（2026 年 4 月上线），存在：
- 流动性不足、滑点大
- Oracle 风险
- 智能合约 bug
- 资金费率机制可能与主流 CEX 不同

→ 务必先用 < $500 小资金完整测试一次开仓-平仓流程。
