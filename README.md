**1. 策略概述**

本策略（VAR-Grid-CV v4.0）定位为**库存驱动的自适应网格做市系统**。  
核心原则不是预测涨跌，而是判断`当前市场是否仍适合均值回归网格`，并在不适合时快速降低逆势库存扩张速度。

策略主线统一为：

`市场预警 -> 状态确认 -> 库存制动 -> 报价执行 -> 尾部修复`

这是一套控制系统，而不是一组独立信号的拼装。

**1.1 设计目标**

- 在震荡环境下持续赚取双边价差。
- 在趋势环境下尽快识别“均值回归逻辑失效”并降低逆势库存扩张。
- 在跳跃环境下优先保命，停止常规近端网格。
- 将坏库存处理收敛到分级减仓与 TWAP 尾部修复。
- 在链上延迟环境下尽量减少无效撤挂和状态幻读。

**1.2 适用市场与场景**

  ---------------- --------------------------- ---------------------------
  **维度**         **适用条件**                **不适用条件**
  市场类型         BTC/ETH 等主流永续合约      极低流动性山寨币
  波动环境         震荡、弱趋势、中等趋势      长时间失序单边行情
  执行环境         可稳定获取订单/持仓回报      高延迟且状态回报不稳定
  运行方式         7×24 小时持续运行           单次重仓押方向
  ---------------- --------------------------- ---------------------------

**2. 系统架构**

策略由四层控制架构组成：预警层、确认层、制动层、执行层。

**2.0 部署前提**

对于 Lighter 这类 ZK-Rollup 环境，以下前提必须满足：

- 所有状态计算基于`已确认订单状态`与`已确认持仓状态`
- 快层轮询频率不得高于实际 batch 刷新与订单回报频率
- 若撤单确认、下单确认、持仓回报出现明显滞后，策略必须自动进入防守模式
- 禁止按 CEX 毫秒级撮合逻辑设计链上报价行为

**2.1 四层控制架构**

  ------------- --------------------- --------------------------------------------
  **控制层**    **模块**              **职责**
  预警层        FastSignalEngine      用快信号判断市场是否开始偏离震荡结构
  确认层        MarketStateEngine     用慢信号确认震荡 / 趋势 / 跳跃状态
  制动层        InventoryBrakeEngine  用库存结果约束是否继续扩大逆势库存
  执行层        LighterGridStrategy   生成双边 / 防守报价模板并执行撤补单、减仓、TWAP
  ------------- --------------------- --------------------------------------------

**2.2 周期执行流程**

策略执行分为快慢两层：

- 快层（1-2 秒）：刷新 BBO、盘口、成交、仓位、挂单状态，运行预警层与库存制动层
- 慢层（3-5 秒）：运行状态确认层，重建报价模板

标准流程：

- 步骤 1：读取已确认净仓位、分档库存、保证金占用、未成交挂单
- 步骤 2：获取 BBO、盘口深度、短周期成交流、短中周期价格序列
- 步骤 3：运行快信号预警层
- 步骤 4：运行慢信号确认层
- 步骤 5：运行库存结果制动层
- 步骤 6：根据控制层结果选择报价模板
- 步骤 7：执行撤单、补单、减仓与 TWAP 清洗

**4. 四层控制逻辑**

**4.1 第一层：快信号预警层**

这一层不负责直接切换趋势态，只负责提前踩刹车。

快信号组成：

- `短时价格斜率`：价格是否开始连续偏离局部中枢
- `OBI`：盘口失衡是否持续同向偏移
- `主动成交方向`：主动买/卖成交是否连续偏单边
- `Spread / Depth`：价差是否扩大、近端深度是否变薄

预警层输出：

- `正常`
- `轻度预警`
- `强预警`

对应动作：

- 正常：维持当前报价模板
- 轻度预警：减少近端逆势挂单层数
- 强预警：扩大近端间距，压缩逆势成交优先级

注意：

- 预警层不能单独把策略切入趋势态
- 预警层只允许影响前 `NEAR_TOUCH_LEVELS` 层近端挂单
- 预警层只负责减速，不负责换挡

**4.1.1 快预警规则表**

  ---------- -------------------------------------- ------------------------- ------------------------------------
  **级别**   **触发条件**                           **持续要求**              **动作**
  正常       快信号均未超阈值                        无                        保持当前模板
  轻度预警   任一快信号超阈值                        连续 1-2 个快层周期       缩减近端逆势 1 层，近端间距扩大 10%-20%
  强预警     任意 2 个快信号同时超阈值               连续 2-3 个快层周期       缩减近端逆势 1-2 层，近端间距扩大 20%-40%
  跳跃预警   价格急变 + spread 扩大 + depth 下降     单次即可触发             直接交由跳跃态确认，快层立即进入防守减速
  ---------- -------------------------------------- ------------------------- ------------------------------------

快信号建议量化口径：

- `短时价格斜率`：近 `10-30 秒` mid price 偏离局部中枢达到 `k_fast1 * Sigma_short`
- `OBI`：连续 `2-3` 个快层周期偏离 `OBI_MICRO_ADJUST_THRESHOLD`
- `主动成交方向`：主动买/卖成交量比持续失衡达到 `1.5x-2.5x`
- `Spread / Depth`：spread 扩大至近均值的 `1.5x-2x`，或近端深度下降至近均值的 `50%-70%`

**4.2 第二层：慢信号确认层**

这一层负责真正判断市场属于：

- `震荡态`
- `趋势态`
- `跳跃态`

1. `震荡态`

判断特征：

- 短中周期净涨跌幅接近 0
- 价格反复穿越局部中枢
- 回归行为明显，单边推进不持续
- 快信号预警偶发，但无法持续

报价模板：

- 双边满载网格
- 正常层数
- 正常间距
- 允许正常逆势成交

2. `趋势态`

判断特征：

- 短周期与中周期收益同向
- 价格持续偏离局部中枢
- 回撤浅，反抽弱
- 预警层连续多次发出强预警

趋势态分两级：

- `弱趋势态`：缩减逆势层数、扩大间距、保留部分均值回归能力
- `强趋势态`：停止继续扩大逆势库存，只保留去库存方向挂单和远端防守单

3. `跳跃态`

判断特征：

- 短时收益超过阈值
- 波动率瞬时抬升至平时数倍
- spread 扩大明显、盘口深度骤降
- 库存风险接近上限

报价模板：

- 关闭常规近端网格
- 仅保留远端防守挂单
- 优先减仓
- 若超过 `JUMP_MAX_HOLD_MINUTES` 仍无法去库存，则进入冻结新开仓模式

**4.2.1 状态切换规则表**

  ------------------ -------------------------------------------- ------------------------- ------------------------------------
  **切换路径**       **进入条件**                                 **确认要求**              **退出条件**
  震荡 -> 弱趋势     价格行为成立 + 强预警反复出现                连续 `STATE_CONFIRM_TICKS` 次  价格回归中枢且强预警消退
  弱趋势 -> 强趋势   价格持续单边推进 + 库存修复速度显著下降       连续 `2-3` 个慢层周期         库存回落至软限下方且单边推进减弱
  强趋势 -> 弱趋势   单边推进减弱 + 库存不再继续恶化              连续 `STATE_EXIT_TICKS` 次     重新满足强趋势条件则回切强趋势
  弱趋势 -> 震荡     价格回归中枢 + 预警层恢复正常                连续 `STATE_EXIT_TICKS` 次     任一慢信号再度恶化则维持弱趋势
  任意 -> 跳跃       短时收益异常 + spread 扩大 + depth 明显下降   单次即可触发                 波动率、spread 回落并完成库存重评估
  跳跃 -> 强趋势     极端波动结束但单边推进仍持续                  连续 `1-2` 个慢层周期         再度触发跳跃条件则回切跳跃
  跳跃 -> 弱趋势     极端波动结束且库存仍偏斜                      连续 `1-2` 个慢层周期         库存恶化则升回强趋势
  跳跃 -> 震荡       极端波动结束 + 库存恢复中性                   连续 `STATE_EXIT_TICKS` 次     重新满足趋势条件则进入趋势
  ------------------ -------------------------------------------- ------------------------- ------------------------------------

补充定义：

- `价格行为成立`：短周期与中周期收益同向，且价格偏离局部中枢超过 `k_slow1 * Sigma_mid`
- `库存修复速度显著下降`：单位时间内自然对冲比例下降到正常震荡期的 `30%-50%`
- `库存不再继续恶化`：连续多个慢层周期内库存累积速度接近 0 或转负

**4.3 第三层：库存结果制动层**

库存不是盘口，而是策略自身已成交、尚未自然对冲掉的仓位风险。

库存至少包括：

- 净仓位（Net Position）
- 多头 / 空头库存
- 分档持仓成本
- 库存占权益比例
- 库存累积速度
- 库存修复速度
- 单笔库存集中度

制动层逻辑：

1. `库存中性`

- 双边报价正常

2. `库存偏斜`

- 允许做市
- 但削弱继续扩大该方向库存的挂单

3. `库存软限`

- 压缩逆势挂单层数
- 扩大逆势间距
- 提高去库存方向成交优先级

4. `库存硬限`

- 停止继续扩大逆势库存
- 只允许去库存和远端防守挂单
- 若慢层仍判定震荡态，也必须服从库存硬限

结论：

- `库存制动`永远高于`状态机模板`
- 趋势判断解决“市场变了吗”
- 库存制动解决“还能不能继续按原逻辑做”

**4.3.1 库存分层规则表**

  ---------- ------------------------------------- ------------------------------------ ------------------------------------
  **层级**   **库存占权益比例**                    **特征**                             **动作**
  中性区     `< 0.5 * INVENTORY_SOFT_LIMIT`        库存均衡，修复正常                   双边正常报价
  偏斜区     `0.5 * SOFT_LIMIT ~ SOFT_LIMIT`       单边库存开始累积                     削弱该方向近端扩张，提升修复优先级
  软限区     `SOFT_LIMIT ~ HARD_LIMIT`             单边库存明显堆积                     缩减逆势层数，扩大逆势间距，压缩风险预算
  硬限区     `>= INVENTORY_HARD_LIMIT`             均值回归逻辑已明显失效               停止扩大逆势库存，仅允许去库存和远端防守
  ---------- ------------------------------------- ------------------------------------ ------------------------------------

库存辅助指标建议：

- `库存累积速度`：单位时间新增单边库存 / 账户权益
- `库存修复速度`：单位时间自然对冲库存 / 账户权益
- `库存集中度`：最大单笔库存 / 总库存

**4.4 第四层：执行与修复层**

这一层只负责把前三层控制结果转换成具体动作：

- 选择报价模板
- 调整层数、间距、中心价
- 撤销冲突挂单
- 执行减仓
- 启动 TWAP 清洗

执行优先级：

- 先判库存硬限
- 再判跳跃态
- 再判趋势态 / 震荡态
- 最后应用预警层对近端挂单的微调

**5. 报价模板系统**

**5.1 震荡模板**

- 双边挂单
- 正常层数
- 正常间距
- 正常 AS 偏移

适用：

- 均值回归有效
- 库存能自然修复

**5.2 趋势模板**

- 弱趋势：减少逆势近端层数，拉宽逆势间距
- 强趋势：停止扩大逆势库存，仅保留去库存方向和远端防守单

适用：

- 市场仍可做市，但均值回归效率已下降

**5.3 跳跃模板**

- 停止常规近端网格
- 仅保留极远端防守单
- 优先减仓，不追求价差收益

适用：

- 短时单边爆发
- 流动性明显恶化

**5.4 报价动作矩阵**

  ---------- ------------------------ --------------------- -------------------------- ------------------------------ -------------------------
  **模板**   **挂单层数**             **间距倍数**          **中心价偏移**             **是否允许继续逆势成交**       **TWAP 并行**
  震荡态     `BASE_GRID_ORDERS`       `1.0x`               正常 AS 偏移               允许                           不启用或仅观察
  弱趋势态   `BASE_GRID_ORDERS * 50%-70%` `1.2x-1.8x`     向去库存方向轻度偏移       允许，但仅限缩减后的近端层      允许观察，不主动清洗
  强趋势态   `BASE_GRID_ORDERS * 20%-40%` `1.8x-2.5x`     向去库存方向明显偏移       原则上不允许继续扩大逆势库存    可并行轻度/中度清洗
  跳跃态     `0-2` 防守层             `2.5x-4.0x`         以防守和减仓为主，不追求成交  不允许常规逆势成交              可并行，但需受流动性窗口约束
  ---------- ------------------------ --------------------- -------------------------- ------------------------------ -------------------------

动作矩阵解释：

- `挂单层数` 指单侧有效挂单层数，实际值需向交易所最小挂单单位取整
- `间距倍数` 以震荡模板的 `GRID_INTERVAL_BPS` 为基准
- `中心价偏移` 优先服从库存方向，其次才服从 AS 连续偏移
- `继续逆势成交` 的限制，针对的是“继续扩大逆势库存”，不是禁止正常网格在震荡态逆势成交

**5.5 模板动作细则**

1. `震荡态`

- 维持双边正常层数
- 允许完整均值回归逻辑
- 允许 OBI 仅对前 `NEAR_TOUCH_LEVELS` 层做小幅微调
- 不主动启动 TWAP，只允许坏库存进入观察队列

2. `弱趋势态`

- 逆势方向近端层数减少到基础层数的 `50%-70%`
- 逆势方向间距扩大到基础间距的 `1.2x-1.8x`
- 顺势方向可保留较远端流动性，但不得转为追涨杀跌模板
- 若库存继续恶化，则优先升级到强趋势态，而不是继续缩小步长试错

3. `强趋势态`

- 停止继续扩大逆势库存
- 仅保留去库存方向挂单和远端防守挂单
- 中心价向去库存方向明显偏移，但仍受 `AS_SHIFT_CLAMP_BPS` 限制
- 若库存处于软限上沿或硬限区，允许 TWAP 轻度/中度并行执行

4. `跳跃态`

- 停止常规近端网格
- 仅保留 `0-2` 层极远端防守单，避免在最差流动性点位连续成交
- 不允许常规逆势成交
- TWAP 仅在波动率与 spread 从峰值回落后启动，否则只做观察和冻结新开仓

**5.6 模板恢复规则**

  ---------- -------------------------------------- ------------------------------------
  **当前模板** **恢复条件**                           **恢复动作**
  跳跃态       波动率回落 + spread 修复 + 库存重评估   先降为强趋势或弱趋势，不直接回震荡
  强趋势态     单边推进减弱 + 库存不再恶化            降为弱趋势态
  弱趋势态     快预警恢复正常 + 价格回归局部中枢       降为震荡态
  震荡态       再次出现连续强预警 + 慢层确认           升为弱趋势态
  ---------- -------------------------------------- ------------------------------------

**6. AS 中心价偏移**

AS 模型保留，但只作为库存导向的中心价偏移工具，不再被描述为核心护城河。

> **Reservation Price = Mid_Price - (Inventory * Gamma * Volatility^2)**

约束：

- `Volatility` 必须统一为同一时间尺度下的短周期实现波动率
- `Inventory` 必须统一为 `净名义敞口 / 账户权益`
- 所有输入先做标准化后再代入
- 偏移量必须截断：`AS_Shift = clamp(raw_shift, -AS_SHIFT_CLAMP_BPS, +AS_SHIFT_CLAMP_BPS)`

作用：

- 多头库存过重：中心价下移，提升卖出优先级
- 空头库存过重：中心价上移，提升买回优先级

**7. TWAP 尾部修复**

TWAP 不是主风控，而是尾部修复工具。

使用顺序必须是：

- 先库存制动
- 再模板切换
- 再减少冲突挂单
- 最后才用 TWAP 清洗

**7.1 死库存定义**

满足以下任一条件可进入观察队列：

- `持仓时间 > 2-4 小时` 且 `浮亏/偏离成本 > 1.5-3 倍基础网格间距`
- `持仓时间 > 2-3 小时` 且 已跨越多个状态周期仍未自然对冲
- 单笔库存占总库存比例过高，且已失去近端成交修复能力
- 浮亏金额或偏离距离先达到硬阈值

**7.2 TWAP 触发窗口**

- 不要求完全低风险
- 要求跳跃极值结束、短时波动率已回落
- 要求 spread 已较峰值明显回落
- TWAP 启动后，必须暂停与清洗方向冲突的同向挂单

**7.3 TWAP 执行规则表**

  ---------- ---------------------------------------- ------------------------------------ ------------------------------------
  **阶段**   **触发条件**                             **执行动作**                         **停止条件**
  观察队列   死库存满足任一观察条件                    标记库存档位，暂停冲突方向近端挂单    价格自然修复或进入正式清洗
  轻度清洗   偏离扩大但流动性尚可                      每轮清洗总库存的 `5%-10%`            偏离收敛或流动性恶化
  中度清洗   偏离持续扩大且库存集中度升高              每轮清洗总库存的 `10%-20%`           偏离收敛、库存回到软限下方
  强制清洗   硬限持续 + 多轮清洗无改善                  每轮清洗总库存的 `20%-30%` 上限      触发人工接管或库存显著回落
  ---------- ---------------------------------------- ------------------------------------ ------------------------------------

TWAP 补充约束：

- 单轮清洗金额不得超过账户权益的 `2%-5%`
- 若连续 `3-5` 轮清洗后库存改善不足 `20%`，必须升级处理级别
- 若流动性再次恶化或重新进入跳跃态，暂停 TWAP，等待下一窗口
- TWAP 期间禁止恢复与清洗方向冲突的近端挂单

**9.2 参数归一化原则**

- 所有价格类参数优先使用 `bps`
- 所有波动类参数优先使用统一时间尺度下的 `Sigma`
- 所有库存类参数优先使用 `占权益比例`
- 所有状态切换类参数优先使用 `持续时间 + 连续确认次数`

建议公式：

`GRID_INTERVAL_BPS = max(Fee_BPS * 2 + Slippage_Buffer_BPS, k1 * Sigma_short_bps, Tick_BPS_Floor)`

**11. 风险提示**

1. **持续单边风险**：即使采用四层控制，长期单边行情仍可能使库存修复效率显著下降。
2. **链上延迟风险**：状态回报滞后会直接削弱快层预警与库存制动效果。
3. **流动性恶化风险**：跳跃态下即使关闭常规网格，也可能因为深度枯竭导致减仓困难。
4. **参数漂移风险**：若快信号、慢信号、库存阈值不统一归一化，策略会出现不同市场下的失真。
