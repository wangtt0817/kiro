# BTC/ETH 同交易所对冲策略

MemeMax Perp DEX 上的 BTC/ETH 永续合约高频配对交易机器人。

## 项目目标

在 MemeMax 永续合约交易所内，通过 BTC 和 ETH 的对冲交易，在保证本金的前提下：

1. **高成交量**：以刷量为核心目标
2. **小额稳定盈利**：每轮微利累积
3. **风险可控**：严格风控，防止单腿敞口和趋势性亏损

---

## 核心策略

**ETH/BTC Ratio 均值回归 + 全 Maker 限价单**

- 监控 ETH/BTC 价格比率对短期 EMA 的偏离
- 偏离 > 0.05% 开仓，回归时平仓
- 所有订单使用 Maker 限价单（费率 0.005% vs Taker 0.15%）
- 每轮成本仅 0.02%，目标毛利 0.05%，净利 0.03%
- 目标频率：每天 20-50 轮，产生 $160k - $400k 的成交量

假设初始资金 $10,000，2x 杠杆：

| 场景 | 日轮次 | 日净利 | 日成交量 | 月收益 |
|------|-------|--------|---------|--------|
| 理想 | 50 | 1.5% | $400,000 | ~45% |
| 正常 | 30 | 0.9% | $240,000 | ~27% |
| 保守 | 20 | 0.6% | $160,000 | ~18% |

> 真实收益取决于市场波动性和挂单成交速度。

## 快速开始

```bash
# 1. 进入策略目录
cd strategy/

# 2. 在 config.py 填入 MemeMax API 凭证
#    API_KEY, API_SECRET, BASE_URL

# 3. 在 exchange_client.py 实现实际 API 调用
#    （每个方法都有说明需要做什么）

# 4. 运行
python main.py
```

详见 `strategy/README.md` 和 `docs/` 文件夹。
